## Tips & Tricks

### Command Palette (`Shift+Cmd+P`)
- Type to search any command
- Examples:
  - `> Format Document`
  - `> Go to Line`
  - `> Toggle Terminal`
  - `> Open Keyboard Shortcuts`
  - `> Preferences: Open Settings`

### Settings
- Open Settings: `Cmd+,`
- Edit in JSON: `Shift+Cmd+P` → "Preferences: Open Settings (JSON)"

### Keyboard Shortcuts
- View all shortcuts: `Cmd+K Cmd+S`
- Customize shortcuts: `Cmd+K Cmd+S`
