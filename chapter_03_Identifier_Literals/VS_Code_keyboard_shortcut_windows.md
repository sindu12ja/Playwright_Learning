## Tips & Tricks

### Command Palette (`Ctrl+Shift+P`)
- Type to search any command
- Examples:
  - `> Format Document`
  - `> Go to Line`
  - `> Toggle Terminal`
  - `> Open Keyboard Shortcuts`
  - `> Preferences: Open Settings`

### Settings
- Open Settings: `Ctrl+,`
- Edit in JSON: `Ctrl+Shift+P` → "Preferences: Open Settings (JSON)"

### Keyboard Shortcuts
- View all shortcuts: `Ctrl+K Ctrl+S`
- Customize shortcuts: `Ctrl+K Ctrl+S`
